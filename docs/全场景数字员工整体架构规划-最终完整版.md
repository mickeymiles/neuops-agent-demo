# 一体化运维·项目·经营·售前 全场景数字员工整体架构规划【最终完整版】

## 一、总体概述与业务闭环

### 1.1 建设背景

现有自研智能体部署于自建云服务器，已落地经营业务分析系统，覆盖IT基础设施运维与经营数据分析。

结合事业部真实全业务链路：**售前投标 → 合同订单 → 集团四算立项 → 两单一物工单任务 → 项目执行 → 日报工时 → 成本核算 → 项目利润复盘 → 集团指标考核**。

公司存在顶层「两单一物」系统，但事业部执行层需要**更精细、前置预警、过程治理、合规管控、自动分析报告**的AI能力，因此搭建全域数字员工体系。

### 1.2 整体业务全闭环（最终完整链路）

**售前方案投标 → 中标合同订单 → 项目概算/预算立项 → 工单任务下发（两单一物） → 里程碑推进 → 员工日报工时填报 → 实时成本核算 → 项目结项决算 → 人均效/元效/双按完成率集团考核 → 联动合同利润率经营大盘**

### 1.3 集团核心管控口径（全域强制纳入监控）

1. **项目四算层级约束（强刚性）**
   概算 ≥ 预算 ≥ 核算 ≥ 决算
   - 预算不可超概算
   - 实时核算不可超已定预算
   - 最终决算不可超过程核算
   一旦越界自动预警、标记集团风险项目。

2. **集团考核指标**
   - 人均效
   - 元效
   - 双按完成率：按期完成率、按预算完成率

### 1.4 核心架构设计原则

1. **固定口径走后端定时任务，动态问答分析走数字员工**
2. **Skill定义能力、MCP定义资源权限，彻底解耦**
3. **只读优先、有限规则配置可变更；AI只研判预警，严禁直接变更原始业务生产数据**
4. **基础设施、AI自身、业务项目、经营利润四层全域可观测**
5. **完全兼容公司两单一物体系，做事业部精细化补强**

### 1.5 全域数字员工总矩阵（7大角色、全覆盖）

1. 运维巡检数字员工
2. 告警&根因分析数字员工
3. 运维开发助手数字员工
4. 经营业务分析数字员工
5. **业务平台编辑辅助数字员工（必选，支持有限规则配置修改）**
6. 项目管理&成本利润治理数字员工（含集团四算/双按/人效元效）
7. 售前投标方案智能组装数字员工

## 二、公共底座与通用规范

### 2.1 底层架构

- 统一智能体管理平台承载所有数字员工逻辑实例
- 所有员工共用大模型底座，通过 **Skill能力 + MCP权限** 做强隔离
- 无多套模型重复部署，轻量化、可扩展

### 2.2 权限总原则

- 所有数字员工**默认只读**
- 原始业务表（合同、付款、工单、工时等）**绝对禁止AI直接写入**
- 仅允许：**业务规则配置、过滤规则、比对开关、排除规则类有限配置变更**；配置变更必须走人工确认审核，AI生成配置方案，人工确认后才真正落库生效
- AI仅负责：巡检、监控、分析、研判、预警、出报告、生成配置变更方案

### 2.3 任务分工铁则

1. 固定统计、月度指标、四算基础计算、人效元效、双按率：**后端定时任务预计算入库**
2. 临时问答、自定义分析、风险研判、合规检查、报告生成：**数字员工承载**
3. 业务规则调整（排除规则、比对开关等）：业务平台编辑辅助数字员工产出变更方案，人工审核确认后执行。

### 2.4 全域MCP工具总清单

#### 运维域 MCP

- `monitor-read`：监控指标时序数据读取
- `log-read`：服务器/数据库/应用/AI全日志检索
- `host-read`：主机、进程、端口、系统状态查询
- `db-read`：数据库只读查询
- `agent-inner-read`：数字员工任务、队列、调用、异常自监控

#### 经营业务域 MCP

- `biz-origin-read`：合同/付款/项目原始业务数据只读
- `biz-metric-read`：所有预计算经营&项目指标统一读取
- `report-export`：报表、分析报告导出
- `biz‑rule‑config‑rw`：**9006经营系统规则配置读写MCP，仅操作规则配置表，禁止触碰业务原始数据表**

#### 项目管理域 MCP（新增）

- `pm-project-read`：项目基础信息、里程碑、四算数据
- `pm-task-read`：两单一物工单、任务明细读取
- `pm-workhour-read`：日报、工时明细、人员填报数据
- `pm-cost-calc`：项目人力成本折算、成本明细

#### 售前投标域 MCP（新增）

- `kb-knowledge-read`：内部知识库、历史方案、中标库
- `bid-template-read`：投标标准模板库、技术规范模板
- `doc-export`：Word/PPT结构化导出

## 三、各数字员工详细能力规格（完整定稿）

## 3.1 运维巡检数字员工

### 定位

全域基础设施+AI自身常态化巡检，保障底层平台稳定。

### 核心能力

1. 基础设施巡检：CPU/内存/磁盘/负载/网络/数据库连接&慢查询
2. AI自巡检：任务队列、MCP调用失败、长任务卡死、Token异常、实例离线
3. 定时日检/小时检 + 人工按需触发专项巡检
4. 自动输出巡检报告、风险分级、整改建议

### 绑定工具

monitor-read、host-read、db-read、agent-inner-read

### 核心Skill

巡检流程编排、风险分级判定、标准化报告输出

---

## 3.2 告警&根因分析数字员工

### 定位

全域告警治理中心，统一运维、业务、AI三类告警降噪与根因研判。

### 核心能力

1. 告警聚合、去重、抖动抑制、风暴压制
2. 基础设施故障根因、数据库故障根因、AI智能体异常根因分析
3. 故障分级、处置建议、风险溯源
4. 支持工单生成、故障复盘报告

### 绑定工具

monitor-read、log-read、alarm-read、workorder-rw

### 核心Skill

告警降噪规则、多场景根因推理、故障知识库

---

## 3.3 运维开发助手数字员工

### 定位

运维研发辅助，只生成、不执行，提升运维研发效率。

### 核心能力

1. 自动生成Shell脚本、运维命令、业务SQL、配置片段
2. 日志智能排错、服务异常定位、启动失败分析
3. 配置解读、风险核查、问题排查方案输出

### 权限约束

**无任何自动执行、写配置、改库权限**

### 绑定工具

log-read、host-read、db-read

### 核心Skill

脚本生成、日志故障分析、配置合规核查

---

## 3.4 经营业务分析数字员工

### 定位

合同、回款、资金占用、毛利率、现金流的动态经营分析中枢。

### 核心能力

1. 自然语言问答经营数据
2. 多维度合同、回款、逾期、毛利自定义分析
3. 资金占用成本测算、经营异动识别
4. 经营日报/周报/专项分析报告自动输出

### 绑定工具

biz-origin-read、biz-metric-read、report-export

### 核心Skill

经营口径标准化、毛利&资金测算、经营报告模板

---

## 3.5 业务平台编辑辅助数字员工（**必选**）

### 定位

面向9006经营业务分析系统，做文件解析比对、**有限业务计算规则配置辅助**。

> 重要边界：**只能修改规则配置表，严禁修改合同、付款等原始业务数据表；所有配置变更方案必须人工确认审核后方可生效**。

### 核心能力

1. 合同/报价附件自动解析、关键字段提取
2. 多版本文件差异比对、风险点标记
3. 针对9006系统，生成**计算规则、排除规则、比对开关类配置变更方案**
    - 示例场景：新增某类数据排除规则；关闭价格比对规则；调整参数匹配逻辑等
4. 输出变更前后配置对比，说明变更带来的业务影响，供人审核
5. 报表配置、口径配置建议输出

### 权限约束

1. 不允许直接修改原始业务数据表；仅可读写**规则配置表**
2. AI产出配置变更方案，**不能直接提交生效；必须人工确认审批后，才调用MCP写入配置**
3. 每一条规则修改完整留存审计日志：修改内容、AI生成内容、操作人、时间

### 绑定工具

file‑parse、biz‑config‑read、**biz‑rule‑config‑rw**

### 核心Skill

附件解析比对Skill、经营规则变更生成Skill、配置变更影响评估Skill

---

## 3.6 项目管理&成本利润治理数字员工（核心增强版）

### 定位

承接公司两单一物体系，**事业部精细化项目过程治理 + 集团口径指标监控**，打通项目进度、工时、成本、利润、集团考核全链路。

### 核心能力

#### 1）项目全生命周期管控

- 里程碑跟进、逾期预警、任务积压识别
- 项目成员负载、忙闲、投入度分析

#### 2）日报&工时合规治理（事业部刚需）

- 日报内容规范性质检，识别敷衍、空填、不匹配任务
- 工时异常预警：溢出、少填、堆填、错绑工单
- 输出每日填报整改清单、部门合规率统计

#### 3）四算刚性约束监控（集团口径）

- 自动校验：**概算≥预算≥核算≥决算**
- 识别所有越界风险项目：超概算、超预算、超核算
- 输出四算对比台账、偏差分析、风险预警报告

#### 4）集团考核指标监控

- 自动汇聚、展示、异动预警：人均效、元效
- 自动统计**双按完成率**（按期完成率、按预算完成率）
- 跟踪事业部月度集团指标达成情况

#### 5）工时→成本→利润闭环联动

- 日报工时自动折算人力成本
- 项目实时动态核算成本
- 预算比对超支预警
- 项目真实利润率与合同目标利润联动复盘

#### 6）两单一物数据对齐校验

工单、任务、工时三者一致性校验，补全上层系统精细化管控盲区

### 绑定工具

pm-project-read、pm-task-read、pm-workhour-read、pm-cost-calc、biz-metric-read

### 核心Skill

日报合规质检、工时异常识别、四算约束校验、集团指标监控、项目成本测算、项目治理报告生成

---

## 3.7 售前投标方案智能组装数字员工

### 定位

基于知识库快速标准化产出投标材料，统一售前输出质量、大幅降本提效。

### 核心能力

1. 行业&场景智能匹配历史方案、剔除冗余、精准拼装（不堆砌）
2. 自动生成：
   - 技术方案建议书（完整版/简版）
   - 招标文件点对点技术应答
   - 售前汇报PPT大纲+正文
   - 运维方案、实施方案、项目优势内容
3. 自动规避过期口径、错误参数，标准化事业部售前话术
4. 支持按需定制客户化版本

### 绑定工具

kb-knowledge-read、bid-template-read、doc-export

### 核心Skill

方案智能拼装、行业适配改写、投标合规自检、PPT结构化生成

## 四、统一运行与治理规范（强制执行）

1. **数据分层**
   原始数据：业务系统、两单一物、项目库、经营库
   指标数据：后端定时任务预计算
   配置数据：规则配置独立数据表，与业务原始数据物理隔离
   智能能力：数字员工做研判、预警、分析、输出、生成配置变更方案

2. **安全底线**
   - 所有AI操作**无高危执行权限**
   - AI**禁止直接写入原始业务数据表**
   - 仅允许生成规则配置变更，变更必须人工确认审批

3. **可观测治理**
   所有数字员工任务、MCP调用、异常日志、**规则配置变更全链路审计日志**全量留存，统一监控。

4. **业务闭环最终效果**
   从**售前→合同→项目→执行→成本→利润→集团考核**
   全部实现：**自动化监控、自动化校验、自动化预警、自动化出报告；支持有限AI辅助规则调优**。

## 六、整体架构一句话总结

整套7大数字员工体系，**全覆盖运维、研发、经营、项目管理、集团考核、售前投标**，
既守住IT底座稳定，又打通事业部从售前到结项利润的**全业务、全数据、全管控、全预警闭环体系；支持AI辅助调整业务计算规则，强管控只改配置不动原始业务数据**。
