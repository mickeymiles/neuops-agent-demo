# 设计：数字员工业务工作台

> 变更编号：`20260820-employee-workbench`
> 日期：2026-08-20 | 状态：已评审

## 技术方案

员工表增加 `workbench_json` 文本列。数据层负责 JSON 编解码，路由层负责白名单结构校验；完整员工接口在无自定义配置时按员工类型返回默认配置。前端以固定渲染器展示五类组件，并通过既有员工 PATCH 接口保存配置。

经营分析默认工作台包含 `business_app` 组件，以 iframe 嵌入 contract 页面。iframe 地址由服务端根据 `BIZ_9006_PUBLIC_BASE` 或当前访问主机解析，配置 JSON 不能携带 URL，防止任意外站嵌入。

后续对话调整复用同一配置契约：模型产出候选配置补丁，服务端校验，用户确认后 PATCH；算法仅允许引用预注册的数据源/算法标识，不接受可执行代码。本轮不实现该流程。

## 数据模型变更

`employees.workbench_json TEXT DEFAULT ''`，启动时幂等补列。空字符串表示使用员工类型默认配置。

## 兼容性说明

旧库无需离线迁移；旧接口调用方忽略新增字段即可。恢复默认写入空配置，不删除员工其他设置。
